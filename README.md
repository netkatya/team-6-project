# 👥 Team Project

Live Demo: [https://netkatya.github.io/team-6-project/](https://netkatya.github.io/team-6-project/)

This is a collaborative front-end project built by **Team 6** using **HTML**, **CSS**, and a bit of **JavaScript**. It focuses on clean layout, responsive design, and basic interactivity.

As the **team lead**, I was responsible for organizing the workflow, assigning tasks, resolving merge conflicts, and ensuring smooth communication between team members.

---

## 🧰 Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla)

---

## ✨ Features

- Fully responsive web layout  
- Mobile-first design  
- Clean, semantic, and accessible HTML  
- Organized and modular CSS structure  
- Minor JavaScript for dynamic UI elements
